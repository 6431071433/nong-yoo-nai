# น้องอยู่ไหน · วิธีขึ้นเว็บแบบฟรี

ใช้ 2 บริการ ฟรีทั้งคู่ ไม่ต้องผูกบัตร
- **Supabase** = ฐานข้อมูลกลาง (ประกาศ รูป เบาะแส)
- **GitHub Pages** = เว็บไซต์ ได้ที่อยู่ `ชื่อคุณ.github.io/nong-yoo-nai`

คนที่เปิดเว็บ **ไม่ต้องสมัครอะไร** ระบบให้รหัสผู้ใช้อัตโนมัติ ลงประกาศได้ทันที แก้ได้เฉพาะประกาศของตัวเอง

## ส่วนที่ 1 · ตั้งฐานข้อมูล (ราว 10 นาที)
1. เข้า supabase.com → Start your project → เข้าสู่ระบบด้วย GitHub
2. New project → ตั้งชื่อ `nong-yoo-nai` → ตั้งรหัสผ่านฐานข้อมูล (จดเก็บไว้) → Region เลือก **Southeast Asia (Singapore)** → แพ็กเกจ **Free** → Create
3. รอราว 2 นาทีจนโปรเจกต์พร้อม
4. เมนูซ้าย **SQL Editor** → New query → วางเนื้อหาทั้งไฟล์ `supabase-setup.sql` → กด **Run** (ขึ้น Success ก็ใช้ได้ ไฟล์นี้สร้างที่เก็บวิดีโอ `videos` ให้ด้วย)
   ถ้าเคยรันไฟล์เวอร์ชันก่อนไปแล้ว ให้รันไฟล์ใหม่นี้ซ้ำอีกรอบได้เลย ข้อมูลเดิมไม่หาย
5. เมนูซ้าย **Authentication** → **Sign In / Providers** → เปิด **Allow anonymous sign-ins** → Save
6. เมนูซ้าย **Project Settings** → **API Keys** (หรือ Data API) → คัดลอก
   - **Project URL** (หน้าตาแบบ `https://xxxx.supabase.co`)
   - **anon public key** (ขึ้นต้นด้วย `eyJ...` อยู่ในแท็บ Legacy API keys)

   สองค่านี้เปิดเผยได้ ความปลอดภัยอยู่ที่กฎในไฟล์ SQL
   **ห้ามใช้ service_role key หรือรหัสผ่านฐานข้อมูลในเว็บเด็ดขาด**

## ส่วนที่ 2 · ใส่ค่าลงในไฟล์เว็บ
เปิด `index.html` ด้วยโปรแกรมแก้ข้อความ (Notepad ก็ได้) → ค้นคำว่า `SUPABASE_URL` → ใส่ค่าในเครื่องหมาย '' สองบรรทัดนี้
```
const SUPABASE_URL='https://xxxx.supabase.co';
const SUPABASE_ANON_KEY='eyJ...';
```
หรือส่งสองค่านี้ให้ Claude ใส่ให้ก็ได้

## ส่วนที่ 3 · ขึ้นเว็บด้วย GitHub Pages (ราว 5 นาที)
1. github.com → มุมขวาบน **+** → **New repository** → ชื่อ `nong-yoo-nai` → เลือก **Public** → Create
2. กด **uploading an existing file** → ลาก `index.html` ลงไป → **Commit changes**
3. แท็บ **Settings** → เมนูซ้าย **Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. รอ 1–2 นาที แล้วรีเฟรช หน้าเดิมจะขึ้นลิงก์เว็บ `https://ชื่อคุณ.github.io/nong-yoo-nai/`

## ส่วนที่ 4 · ตั้งตัวเองเป็นผู้ดูแล (ทำทันทีหลังเปิดเว็บครั้งแรก)
1. เปิดเว็บ → สร้างตัวละคร → เมนู **นักสืบของฉัน** → เลื่อนลงล่าง → กด **ตั้งตัวเองเป็นผู้ดูแล**
2. ปุ่ม **ผู้ดูแล** จะขึ้นที่มุมขวาบนของเมนู → เข้าไปกด **เติมข้อมูลตัวอย่าง** ถ้าอยากให้แผนที่มีของให้ดูก่อน
3. **จดรหัสผู้ใช้** ที่แสดงในหน้านักสืบของฉันเก็บไว้ ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง สิทธิ์ผู้ดูแลจะหาย กู้คืนได้โดยรันใน SQL Editor:
   `insert into public.admins (uid) values ('รหัสผู้ใช้ใหม่');`

## แก้ไขเว็บภายหลัง
อัปโหลด `index.html` ไฟล์ใหม่ทับใน GitHub (Add file → Upload files) เว็บจะอัปเดตเองใน 1–2 นาที ข้อมูลในฐานข้อมูลไม่หาย

## ข้อจำกัดของแพ็กเกจฟรี
- Supabase จะ **หยุดชั่วคราวถ้าไม่มีใครใช้ 1 สัปดาห์** เข้าไปกด Restore ในหน้า Supabase ได้ ข้อมูลไม่หาย
- ฐานข้อมูล 500 MB (รูปถูกบีบไว้ เก็บได้หลายพันรูป) รับส่งข้อมูล 5 GB ต่อเดือน
- วิดีโอเก็บในพื้นที่ Storage ฟรี 1 GB (คลิปละไม่เกิน 25 MB ยาวไม่เกิน 60 วินาที ราว 40–100 คลิป) ดูว่าเหลือเท่าไรได้ที่เมนู **Storage → videos** ลบคลิปเก่าของประกาศที่ปิดแล้วเพื่อคืนพื้นที่
- วิดีโอจาก iPhone ที่เป็น .mov บางไฟล์อาจเล่นไม่ได้บนมือถือ Android บางรุ่น ถ้าเป็นไปได้ให้ตั้งกล้องเป็น "Most Compatible" (ตั้งค่า → กล้อง → รูปแบบ)
- ผู้ใช้แบบไม่ระบุตัวตนผูกกับเบราว์เซอร์ ถ้าล้างข้อมูลเบราว์เซอร์ จะแก้ประกาศเก่าของตัวเองไม่ได้ (ผู้ดูแลยังแก้ให้ได้)
- ยังไม่มีแจ้งเตือนเข้ามือถือตอนปิดเว็บ (เฟสถัดไป)
